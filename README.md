# Bella's Blog 使用说明

这是 Bella 的个人博客，线上地址：

<https://bellabiu888.github.io/bella_blogs/>

这份说明写给完全没有编程经验的人。平时只需要记住三个命令：

```bash
./run.sh new 文件名 "文章标题"   # 创建文章
./run.sh dev                    # 在电脑上预览
./run.sh publish "发布说明"     # 发布到网站
```

下面是完整的操作步骤。

## 一、打开博客文件夹和终端

博客文件夹在：

```text
/Users/bella/codes/bella_blogs
```

在 Mac 上打开“终端”应用，然后输入：

```bash
cd /Users/bella/codes/bella_blogs
```

按下回车。以后本页中的命令，都在这个终端窗口里输入。

第一次使用时，先安装博客需要的组件：

```bash
./run.sh install
```

只需安装一次。看到命令运行结束且没有红色错误，就可以继续。

## 二、创建一篇新文章

在终端输入：

```bash
./run.sh new my-first-post "我的第一篇文章"
```

这里有两处可以修改：

- `my-first-post` 是文章的文件名和网址，只能使用小写英文字母、数字和短横线，不能有空格。
- `我的第一篇文章` 是显示在博客上的文章标题，可以使用中文。

例如，想写一篇杭州游记，可以输入：

```bash
./run.sh new hangzhou-trip "杭州周末旅行"
```

命令运行后，会生成文章文件：

```text
src/content/blog/hangzhou-trip.md
```

## 三、打开并编辑文章

用 VS Code 或其他文本编辑器打开整个 `bella_blogs` 文件夹，然后找到：

```text
src → content → blog → hangzhou-trip.md
```

新文章看起来像这样：

```md
---
title: "杭州周末旅行"
description: 请填写一句话简介
pubDate: 2026-07-12
tags: [随笔]
draft: true
---

从这里开始写正文。
```

顶部两行 `---` 之间是文章信息：

- `title`：文章标题。
- `description`：文章简介，会显示在博客首页。
- `pubDate`：发布日期，格式必须是“年-月-日”。
- `tags`：文章分类。多个分类可以写成 `[旅行, 生活]`。
- `draft`：是否为草稿。`true` 表示隐藏，`false` 表示可以发布。

文章没写完时保持：

```text
draft: true
```

准备发布时改成：

```text
draft: false
```

不要删除顶部的 `---`，冒号后面也要保留一个空格。

## 四、怎样写正文

这个博客使用 Markdown。它和普通文字很像，只需要几个简单符号。

### 标题

```md
## 这是大标题

### 这是小标题
```

文章自己的标题已经写在顶部的 `title` 中，正文一般从 `##` 开始。

### 普通段落

直接写文字即可。段落之间留一个空行：

```md
这是第一段文字。

这是第二段文字。
```

### 列表

```md
- 西湖
- 灵隐寺
- 龙井村
```

### 加粗和链接

```md
这是**需要加粗的文字**。

这是一个[网站链接](https://example.com)。
```

### 插入图片

先把图片放进 `public/images/` 文件夹。没有 `images` 文件夹时，可以自己新建一个。

假设图片名为 `hangzhou.jpg`，在文章中这样写：

```md
![西湖风景](/bella_blogs/images/hangzhou.jpg)
```

图片文件名建议只使用小写英文、数字和短横线，不要使用空格或中文。

## 五、发布前在电脑上预览

保存文章后，在终端运行：

```bash
./run.sh dev
```

终端会显示一个本地网址，通常类似：

```text
http://localhost:4321/bella_blogs/
```

按住 Command 键点击网址，或者复制到浏览器打开。

修改并保存文章后，浏览器通常会自动更新。预览结束时，回到终端按 `Control + C` 停止。

注意：`draft: true` 的文章不会出现在预览首页。需要临时预览它时，可以先改成 `draft: false`，确认完成后再决定是否发布。

## 六、正式发布文章

确认以下三件事：

1. 文章已经保存。
2. 日期、标题和简介填写正确。
3. 要发布的文章已经设置为 `draft: false`。

然后在终端运行：

```bash
./run.sh publish "发布杭州周末旅行"
```

引号里的文字只是本次发布说明，可以按文章内容修改。

这个命令会自动：

1. 检查博客能否正常生成。
2. 保存本次修改记录。
3. 上传到 GitHub。
4. 触发 GitHub Pages 更新网站。

看到 `发布已触发` 就表示上传成功。通常等待几十秒到几分钟，再刷新线上地址：

<https://bellabiu888.github.io/bella_blogs/>

## 七、修改已经发布的文章

在 `src/content/blog/` 中找到对应的 `.md` 文件，直接修改并保存，然后再次发布：

```bash
./run.sh publish "修改杭州周末旅行"
```

不需要创建新文件。

## 八、常用命令

```bash
./run.sh install     # 安装博客组件，通常只需运行一次
./run.sh dev         # 启动本地预览
./run.sh build       # 检查博客有没有错误
./run.sh preview     # 预览最终生成的网站
./run.sh status      # 查看文件修改和最近发布状态
./run.sh help        # 查看所有命令
```

## 九、常见问题

### 提示“文件名只能包含小写字母、数字和连字符”

文章文件名不能使用中文、空格或大写字母。可以把 `杭州旅行` 改成 `hangzhou-trip`。

### 新文章没有显示

检查文章顶部是否仍是：

```text
draft: true
```

如果准备公开，改成 `draft: false`，保存后重新发布。

### 发布时提示“没有需要发布的改动”

说明文章没有修改，或者修改后还没有保存。回到编辑器保存文件，再运行发布命令。

### 终端出现构建错误

先检查文章顶部信息是否完整，尤其是：

- 是否保留了开头和结尾的 `---`。
- 日期是否使用 `2026-07-12` 这样的格式。
- 每一项的冒号后面是否有空格。
- 引号和中括号是否成对出现。

修改并保存后，运行：

```bash
./run.sh build
```

检查通过后再发布。
